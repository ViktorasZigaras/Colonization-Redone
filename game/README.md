# v020 Art Workbench

Open the launcher and choose v020. In Campaign, use All art to change the whole look, or mix Terrain, People, Buildings, Ships, Scenery, Goods and Surfaces separately. The selections are saved as display preferences.

- Current uses the existing v019 art.
- Remake uses the paired art concepts as transparent pixel sprites, with new scenery and goods. The terrain is a muted ochre and moss palette with teal water and wide ground color clusters.
- Re-remake gives the sprite set a restrained ink-and-parchment palette. Its terrain uses stepped bands and finer grain. This option is a palette and texture study using the same sprite silhouettes.

All current buildings, 23 roster entries and five playable ship types have remake art. The fluyt concept represents the Merchantman and the brig represents the Privateer. Soldier, Dragoon and Artillery use the military concepts. The extra proposed hulls, formations and press buildings remain art references until their gameplay is designed. Scenery, resources, goods, and colony timber also have alternate assets. Shore geometry, animations, and UI layout are shared.

No simulation rules changed in this art build.
